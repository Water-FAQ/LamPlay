# Порядок выпуска LamPlay

- Обсуждение, анализ и замечания пользователя не являются командой на новую сборку. Начинать изменения для новой сборки только после явной отмашки.
- Пользователь подтвердил 8 ноября 2026: отмашка на сборку включает ее публикацию в GitHub и обновление плагина по постоянной ссылке. Повторное подтверждение публикации для каждой согласованной сборки не требуется.
- При выпуске обновлять номер и дату версии, README.md (история изменений), SOURCES.md (изменения и проверки источников) и AUDIT.md (проверки и ограничения).
- Проверять согласованный объем изменений до публикации. Не выдавать проверку API или браузерного макета за проверку воспроизведения на физическом телевизоре.
- Публиковать без принудительной перезаписи чужих коммитов. Сохранять постоянный адрес https://water-faq.github.io/LamPlay/lamplay.js.
- Сохранять отдельный архив сборки и дополнять общий архив версий, сохраняя предыдущие снимки и соответствие Git-коммитам. Если публикация не выполнена, явно обозначать это в результате и архивных метаданных.
