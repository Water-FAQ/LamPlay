# VeoVeo: индекс каталога

Снимок метаданных от 03.11.2026: 118600 записей. Источник — публичный каталог [Lampac](https://github.com/lampac-nextgen/lampac/blob/main/Core/data/veoveo.json), blob SHA `906042cfaa3e971a021f5ab34d8c03f64c6fdef7`.

Ключи: нормализованное название, ID Кинопоиска или IMDb. Значения: ID VeoVeo и год. Только фактические метаданные; токенов, сессий и видеоссылок нет. Поиск точный, с выбором по году при совпадениях; каталог является снимком и может не содержать новых произведений.

Индекс разделён на 32 JSON-файла. При поиске загружается только нужная часть, которая сохраняется в памяти до перезагрузки Lampa. Общий размер около 15 MB, одна часть — не более 581 KB до HTTP-сжатия. Видеокаталог и потоки запрашиваются у VeoVeo, а не у GitHub Pages.

Пересборка: `python tools/build-veoveo-index.py catalog.json data/veoveo`. Входной файл может быть JSON либо gzip; исполняемый код из каталога не загружается.

## Автоматическое обновление с 0.12.0

`.github/workflows/veoveo-index.yml` запускается по понедельникам в 06:00 UTC (09:00 МСК) и вручную через Actions → Refresh VeoVeo catalog → Run workflow. GitHub может задержать плановый запуск. Скрипт `tools/refresh-veoveo-index.py` скачивает только данные, проверяет полный каталог и строит индекс во временной папке. Пустой, повреждённый, дублирующий ID или резко уменьшившийся каталог не заменяет рабочую базу.

Новые записи и изменения публикуются только при отличиях содержимого, порядок JSON-ключей не считается изменением. `status.json` хранит дату успешной публикации/первичной проверки, число записей и SHA256 исходного ответа. При неизменившемся каталоге дата публикации остаётся прежней, успешность последней проверки видна в Actions.

Основной адрес частей в плагине: текущая ветка `raw.githubusercontent.com/Water-FAQ/LamPlay/main/data/veoveo/`; резерв: GitHub Pages. Обновление ветки ботом не требует новой сборки плагина или отдельной пересборки Pages. После перезагрузки Lampa части читаются заново; в течение сеанса используется кэш в памяти. Существующие серии и потоки всегда получаются из API VeoVeo.
