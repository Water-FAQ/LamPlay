# VeoVeo: индекс каталога

Снимок метаданных от 03.11.2026: 118600 записей. Источник — публичный каталог [Lampac](https://github.com/lampac-nextgen/lampac/blob/main/Core/data/veoveo.json), blob SHA `906042cfaa3e971a021f5ab34d8c03f64c6fdef7`.

Ключи: нормализованное название, ID Кинопоиска или IMDb. Значения: ID VeoVeo и год. Только фактические метаданные; токенов, сессий и видеоссылок нет. Поиск точный, с выбором по году при совпадениях; каталог является снимком и может не содержать новых произведений.

Индекс разделён на 32 JSON-файла. При поиске загружается только нужная часть, которая сохраняется в памяти до перезагрузки Lampa. Общий размер около 15 MB, одна часть — не более 581 KB до HTTP-сжатия. Видеокаталог и потоки запрашиваются у VeoVeo, а не у GitHub Pages.

Пересборка: `python tools/build-veoveo-index.py catalog.json data/veoveo`. Входной файл может быть JSON либо gzip; исполняемый код из каталога не загружается.
