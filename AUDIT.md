## Границы проверки

- Нет доступа к реальному LG пользователя и к подтверждённому аккаунту Filmix.
- Свежие прямые проверки Filmix: «Братья» (187061), «Гангстерленд» (176734), фильм «Братья» (102732): плейлисты и MP4 206 с UA приложения.
- Браузерный Filmix: API 200, но гостевой плейлист пуст. Нельзя выдавать это за исправленное воспроизведение на LG.
- CDNvideohub: плейлист фильма «Матрица» по KP301, четыре озвучки, видеоссылки и MP4 206 через возвращённый сервисом failoverHost. Браузерный API доступен по CORS. Сериалы этого источника не подтверждены.
- Новые прямые источники не считаются рабочими только на основании HTTP200.
