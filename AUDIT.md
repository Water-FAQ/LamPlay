# LamPlay 0.25.0 — проверки 10.11.2026

Отдельная ветка fix/0.25.0 основана на опубликованной main 0.24.0. Внесены согласованные исправления Filmix, навигации результатов/пустого ответа, анимации кэшированных переключений и смещения полос фильтров, Channel +/−, ширины следующей серии и режима цветных статусов.

Локально прошли десять наборов логических/JSDOM-проверок. Новые проверки отправляют KeyboardEvent для стрелок и ChannelUp/Down, проверяют возврат на источник после кэшированного пустого ответа, одинаковое приглушение при повторных переключениях во всех трех видах, режим контура и восстановление исходного оформления. Filmix проверен на последовательность прямых зеркал перед Worker и приватный POST для каждого известного адреса. Реальный пульт и физический ТВ недоступны.

Полный прогон всех 16 наборов успешно завершен: https://github.com/Water-FAQ/LamPlay/actions/runs/42809266163 . Проверенный коммит dce125dbee53b7c83e81c7da31c0f5e81c17dd4e; выпускной коммит меняет только документацию и результаты сетевых проверок.

Браузерный прогон выполнен в GitHub Actions: локальный /usr/bin/chromium завершается при socket() с Operation not permitted. Это ограничение среды, не успешная браузерная проверка. Дополнительный сценарий проверяет реальные события клавиш в Chromium с видимыми элементами, отсутствие центрирования видимой кнопки перевода, минимальное приглушение и максимальную ширину следующей серии с длинным названием под CSS Lampa.

Сетевые проверки и границы подтверждения: [SOURCES.md](SOURCES.md). Видеобайты Filmix 480p получены для двух проверенных записей; полного декодирования или запуска на WebOS здесь нет. Остальные ограничения Worker и кандидатов явно сохранены. Новых функций вне согласованного объема нет.
