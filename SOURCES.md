# Дополнительные источники: проверка после публикации 0.9.0

Дата: 3 ноября 2026. Проверено после публикации a700ba63d332c321febd07b8451b836eb25f8cea. Новые источники в список рабочих не добавлялись.

## Метод

Сверены реализации актуального оригинала https://nb557.github.io/plugins/online_mod.js. Проверялись прямые API/поиск, затем страницы произведений/серии/плееры, если предыдущий шаг доступен. Прикладной прокси в LamPlay не добавлялся. Сетевые результаты относятся к среде проверки, а не к сети пользователя. Ошибки здесь не доказывают, что сервис недоступен всем.

Отдельный Chromium с origin http://lampa.mx не завершил за 10 секунд чтение AnimeLib, FanCDN, Kinobase и внешнего Kodik. Это не подтверждает браузерное воспроизведение и не доказывает конкретную ошибку CORS. Заголовки CORS в серверных ответах отмечены отдельно.

## Исключения

Alloha не проверялась и не добавлялась по указанию пользователя.

RedHeadSound не подключался. Официальный RHS Cinema сообщает о платных тарифах подписки: https://t.me/rhscinema. В каталоге есть метки «Подписчикам»: https://redheadsound.studio/index.php/categories/redheadsound. Бесплатная подписка не подтверждена; платная существует. Обязательность её для абсолютно каждого произведения не установлена.

## Вывод

Самый предметный кандидат — новый API AnimeLib для каталога/серий/озвучек. Полученный iframe Kodik не равен прямому потоку: требуется подтвердить получение и воспроизведение видео в поддерживаемых средах. Для остальных кандидатов текущих подтверждений недостаточно, чтобы объявить их рабочими источниками LamPlay.
