## Исключения

Alloha не проверялась и не добавлялась по указанию пользователя.

RedHeadSound не подключался. Официальный RHS Cinema сообщает о платных тарифах подписки: https://t.me/rhscinema. В каталоге есть метки «Подписчикам»: https://redheadsound.studio/index.php/categories/redheadsound. Бесплатная подписка не подтверждена; платная существует. Обязательность её для абсолютно каждого произведения не установлена.

## Вывод

Самый предметный кандидат — новый API AnimeLib для каталога/серий/озвучек. Полученный iframe Kodik не равен прямому потоку: требуется подтвердить получение и воспроизведение видео в поддерживаемых средах. Для остальных кандидатов текущих подтверждений недостаточно, чтобы объявить их рабочими источниками LamPlay.
