# LamPlay 0.20.0 - 08.11.2026

Постоянный адрес: **https://water-faq.github.io/LamPlay/lamplay.js**

## Изменения 0.20.0

1. Названия серий в Ленте и Витрине уменьшены на 20% и занимают одну строку. Длинные названия завершаются троеточием.
2. Витрина вновь использует крупные миниатюры: около четырёх полных карточек и часть следующей. Убрано уменьшение миниатюр при появлении метаданных. В Ленте увеличен промежуток между верхним блоком и сериями.
3. Возвращено плавное увеличение при выборе: в Ленте и Витрине увеличивается изображение со всеми надписями и контуром, в Списке — вся строка. Расчёт прокрутки не зависит от текущего кадра увеличения. Контур Списка рисуется поверх изображения.
4. Сезоны и озвучки с подтверждённым нулём серий скрыты и исключены из навигации. Не загруженные данные и ошибки не считаются нулём. Сезон по-прежнему показывает максимум среди переводов.
5. До получения метаданных и подготовки первых изображений отображаются заглушки. Первое открытие, смена сезона и перевода используют одинаковый порядок загрузки. Изображения остальных серий начинают загружаться заранее, без ожидания прокрутки. При недоступности дополнительного сервиса предусмотрено ограниченное ожидание и данные источника.
6. Недоступность озвучки не удаляет дату и рейтинг серии. Название поднимается только при отсутствии обоих полей; описание сохраняется, если оно есть.
7. Текст в кнопках и кнопке продолжения выровнен по высоте. Окно результатов использует отступы, обложку и размеры левого блока Списка. Пустое состояние центрируется в области содержимого.
8. Kodik: сначала проверяются названия с годом; фильмы не принимаются за сериал. Разбираются встроенные списки всех сезонов. Отдельные части аниме ищутся по названиям и годам метаданных, затем объединяются с сохранением ссылок и последовательной нумерацией. Для «Атаки титанов» проверены части третьего сезона 12+10 и четвёртого 16+12+2. Собственный API-токен для этого не требуется.
9. Заглушки используют те же оболочки карточек, размеры миниатюр, отступы и двухстрочные фильтры, что и итоговая разметка.

## Проверки 0.20.0

Проверяются разбор нескольких сезонов и частей Kodik, нулевые счётчики, согласованная загрузка при входе и переключении, метаданные недоступных серий. Chromium проверяет геометрию на 720p и 1080p, увеличение, длительность перехода и устойчивость прокрутки. Физический телевизор в автоматической проверке не участвует.

## Проверка браузерных ограничений 3 ноября 2026

Из браузерного origin http://lampa.mx запрос к https://rezka.fi/ не читается. Сам сайт отвечает HTTP200, но без Access-Control-Allow-Origin. Воспроизведено браузерным fetch с обычной политикой безопасности. Вход также требует разрешённых межсайтовых cookies. Подтверждать исправленный браузерный вход нельзя.

Kodik: публичный скрипт и get-player читаются; get-player вернул HTTP200 и ссылку. Последующий fetch страницы kodikplayer.com блокируется. Доступность сайта или успешный подбор сами по себе не означают доступность разбора плеера из браузера. Прокси не добавлен.

CDNvideohub: пользователь подтвердил работу на телефоне в браузере и в приложении LG. Общие изменения интерфейса проверены отдельно на моделируемых данных.

## Filmix: сведения проверки 0.8.0 (уточнены выше)

Адрес мобильного API: `http://filmixapp.cyou/api/v2/`.
При проверке гостевых запросов с User-Agent приложения получены серии «Братьев», «Гангстерленда» и MP4-потоки. С браузерным User-Agent тот же API возвращает пустой плейлист. Lampa использует нативный HTTP-клиент на Android; на LG/webOS запрос остаётся браузерным, и JavaScript не может выставить нужный User-Agent.

Сценарий привязки реализован, но завершение привязки реального аккаунта, подписка и воспроизведение с его токеном на LG не подтверждены. Успешную авторизацию нельзя считать гарантией устранения ограничения. Прокси не добавлен.

В настройках Filmix нажмите «Добавить устройство на Filmix», войдите в свой аккаунт на https://filmix.gg/consoles и введите код, не закрывая окно в Lampa. После подтверждения токен сохранится автоматически. Для HTTP API сама Lampa также должна быть открыта по HTTP.
