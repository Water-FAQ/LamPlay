# LamPlay 0.8.0

## Изменения 0.8.0

- Виды переименованы: Лента, Список, Витрина. Сохранённые настройки совместимы.
- Правое меню использует системный Lampa.Select: сброс, источник, сезон, перевод.
- Общая геометрия заглавного блока Ленты и Списка, более широкая левая колонка; тайминги удалены из «Продолжить» во всех видах.
- Мягкая виньетка Витрины, отдельный цвет значений фильтров, затухание только переполненного текста.
- Контур и увеличение активной серии: вся строка Списка, только миниатюра Ленты/Витрины. Просмотренные имеют тонкий контур.
- Адаптация к узким и невысоким окнам, прокрутка до элементов, перерасчёт после смены ориентации.
- Ошибка занимает область результатов, заменяя серии/заглушки. Повтор доступен с пульта, «Вид» остаётся доступен.
- Индикатор HDrezka перенесён к «Состояние входа».
- Исправлена регистрация поля токена Filmix для обработчика Params Lampa; статус и привязка устройства сохранены.
- AniLiberty: передаются постер релиза, превью и длительность эпизода из ответа источника; одинаковые источник/озвучка не дублируются.

## Проверка браузерных ограничений 3 ноября 2026

Из браузерного origin http://lampa.mx запрос к https://rezka.fi/ не читается. Сам сайт отвечает HTTP200, но без Access-Control-Allow-Origin. Воспроизведено браузерным fetch с обычной политикой безопасности. Вход также требует разрешённых межсайтовых cookies. Подтверждать исправленный браузерный вход нельзя.

Kodik: публичный скрипт и get-player читаются; get-player вернул HTTP200 и ссылку. Последующий fetch страницы kodikplayer.com блокируется. Доступность сайта или успешный подбор сами по себе не означают доступность разбора плеера из браузера. Прокси не добавлен.

CDNvideohub: пользователь подтвердил работу на телефоне в браузере и в приложении LG. Общие изменения интерфейса проверены отдельно на моделируемых данных.

## Filmix: существенное ограничение

Адрес API совпадает с Online Mod: `http://filmixapp.cyou/api/v2/`.
При проверке гостевых запросов с User-Agent приложения получены серии «Братьев», «Гангстерленда» и MP4-потоки. С браузерным User-Agent тот же API возвращает пустой плейлист. Lampa использует нативный HTTP-клиент на Android; на LG/webOS запрос остаётся браузерным, и JavaScript не может выставить нужный User-Agent.

Сценарий привязки реализован, но завершение привязки реального аккаунта, подписка и воспроизведение с его токеном на LG не подтверждены. Успешную авторизацию нельзя считать гарантией устранения ограничения. Прокси не добавлен.

В настройках Filmix нажмите «Добавить устройство на Filmix», войдите в свой аккаунт на https://filmix.gg/consoles и введите код, не закрывая окно в Lampa. После подтверждения токен сохранится автоматически. Для HTTP API сама Lampa также должна быть открыта по HTTP.

## Другие источники

CDNvideohub проверен до MP4 для фильма. Ему нужен `kinopoisk_id` в карточке; самостоятельного поиска по названию нет. Используется резервный адрес видео-CDN из ответа самого сервиса.

Collaps вернул 410 на двух изученных адресах. VeoVeo показал стандартную страницу хостинга, Vibix требует дальнейшего изучения API, пригодность Lumex/Kinobase для прямого браузерного подключения не подтверждена. Они не включены. KinoTochka и KinoPub не изменялись.

## Проверки

122 автоматические проверки интерфейса, настроек, парсеров и регрессий; в предыдущей сборке отдельно выполнены 4 сетевые проверки до сигнатуры MP4. Браузерная проверка подтвердила доступность API CDNvideohub и воспроизвела пустой гостевой плейлист Filmix. Это не испытание на реальном LG.

Для локальных проверок: `npm install`, `npx playwright install chromium`, `npm test`. При необходимости задайте `CHROMIUM_PATH` к установленному Chromium. Сетевые проверки в `npm test` не входят.
