# LamPlay 0.12.0 - 04.11.2026

Постоянный адрес: **https://water-faq.github.io/LamPlay/lamplay.js**

## Изменения 0.12.0

1. Настройки: «Рейтинг», затем «Настройки источников», «Источник по умолчанию» и сразу «Запоминать источник для каждого произведения». Внутри настроек источников: HDrezka, Kodik, AniLiberty, Filmix, новый подраздел VeoVeo со своей иконкой, затем адрес KinoTochka и ожидание ответа. Возврат из вложенного подраздела сохраняет положение в родительском меню.
2. AniMedia временно отключён: отсутствует во всех списках источников, выборе по умолчанию, настройках и фоновой проверке. Адаптер сохранён. Старый выбор и история AniMedia переходят на доступный источник; «Продолжить» не передаёт чужому источнику прежний ID, а выполняет новый поиск.
3. Окно результатов: независимо от выбранных Списка, Ленты или Витрины, слева показаны изображение и логотип. Влево из любого результата переводит к фильтрам; вправо из любого фильтра возвращает к последнему результату. Вверх/вниз перемещают по своей колонке. Эти правила относятся только к результатам, навигация по сериям, сезонам и переводам сохранена.
4. Лента и Витрина: сохранены крупные миниатюры 22vw на ТВ. Ряд поднят ближе к фильтрам с запасом для рамки, сокращён отступ до описания, показываются три полные строки, в том числе на невысоком экране. Убран лимит двух строк и конфликт фиксированной высоты информационного блока.
5. Ошибка источника: с автоматически выделенной кнопки «Повторить попытку» можно перейти к элементам управления пультом. Возврат справа из вертикальной колонки к повтору также работает.
6. Правое меню «Фильтр» → «Источник» использует тот же список с точками доступности, что и кнопка «Источник». Цвет обновляется по общей проверке; на самой кнопке точки не показываются.
7. Во внутреннем плеере Lampa блок следующей серии/озвучки доступен нажатием и пультом. Вверх со шкалы перемотки переводит к этому блоку, вниз возвращает к шкале. Запуск использует штатное переключение плейлиста и сохраняет текущую позицию.
8. Во всём интерфейсе длинные тире заменены короткими дефисами. Из текущих файлов убраны названия и сравнения со сторонними плагинами. Названия источников и ссылки на публичные данные сохранены.
9. Для каталога VeoVeo добавлено еженедельное обновление GitHub Actions: понедельник, 09:00 МСК, также доступен ручной запуск. Входной каталог проверяется перед заменой всех 32 частей, при ошибке старые данные остаются. Публикуются только реальные изменения метаданных. Дата публикации и число записей находятся в `data/veoveo/status.json`; результат каждой проверки виден в Actions.
10. Плагин загружает индекс из текущей ветки GitHub, с резервом GitHub Pages. Это позволяет получать обновления после автоматических коммитов независимо от пересборки Pages. Части остаются в памяти до перезагрузки Lampa; весь каталог при открытии не скачивается.

### Источник по умолчанию и история

«Источник по умолчанию» используется для произведения, у которого нет сохранённого выбора. При включённом «Запоминать источник для каждого произведения» повторное открытие использует сохранённый источник именно этого фильма/сериала. Выбор другого источника сохраняется для этого произведения. При выключенной истории обычное открытие каждый раз начинает с источника по умолчанию. «Продолжить» отдельно восстанавливает источник и озвучку последнего запуска; смена настройки по умолчанию не переписывает сохранённое продолжение.

## Проверка браузерных ограничений 3 ноября 2026

Из браузерного origin http://lampa.mx запрос к https://rezka.fi/ не читается. Сам сайт отвечает HTTP200, но без Access-Control-Allow-Origin. Воспроизведено браузерным fetch с обычной политикой безопасности. Вход также требует разрешённых межсайтовых cookies. Подтверждать исправленный браузерный вход нельзя.

Kodik: публичный скрипт и get-player читаются; get-player вернул HTTP200 и ссылку. Последующий fetch страницы kodikplayer.com блокируется. Доступность сайта или успешный подбор сами по себе не означают доступность разбора плеера из браузера. Прокси не добавлен.

CDNvideohub: пользователь подтвердил работу на телефоне в браузере и в приложении LG. Общие изменения интерфейса проверены отдельно на моделируемых данных.

## Filmix: сведения проверки 0.8.0 (уточнены выше)

Адрес мобильного API: `http://filmixapp.cyou/api/v2/`.
При проверке гостевых запросов с User-Agent приложения получены серии «Братьев», «Гангстерленда» и MP4-потоки. С браузерным User-Agent тот же API возвращает пустой плейлист. Lampa использует нативный HTTP-клиент на Android; на LG/webOS запрос остаётся браузерным, и JavaScript не может выставить нужный User-Agent.

Сценарий привязки реализован, но завершение привязки реального аккаунта, подписка и воспроизведение с его токеном на LG не подтверждены. Успешную авторизацию нельзя считать гарантией устранения ограничения. Прокси не добавлен.

В настройках Filmix нажмите «Добавить устройство на Filmix», войдите в свой аккаунт на https://filmix.gg/consoles и введите код, не закрывая окно в Lampa. После подтверждения токен сохранится автоматически. Для HTTP API сама Lampa также должна быть открыта по HTTP.

## Другие источники

## Проверки

138 автоматических проверок интерфейса, настроек, парсеров и регрессий; в предыдущей сборке отдельно выполнены 4 сетевые проверки до сигнатуры MP4. Браузерная проверка подтвердила доступность API CDNvideohub и воспроизвела пустой гостевой плейлист Filmix. Это не испытание на реальном LG.
