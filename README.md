# LamPlay 0.9.0

## Изменения 0.9.0

- Виньетка Витрины рисуется отдельным слоем градиентов поверх фоновой картинки, с более мягким затемнением. Она не зависит от поддержки маски изображения в WebOS.
- У Ленты и Списка одинаковая геометрия изображения, логотипа, кнопки «Продолжить» и информации о серии. Проверяются размеры и координаты каждого элемента.
- Контур запущенной серии утолщён до 2px. Успешный запуск плеера сохраняет отдельную отметку даже при нуле секунд; ошибка до получения потока её не ставит. Метка не подменяет процент просмотра.
- Прокрутка серий удерживает выбранную карточку около центра области; повторные нажатия перенаправляют текущую анимацию. У краёв положение ограничено содержимым. Добавлен запас для увеличенной миниатюры и её контура.
- Исправлены переходы вниз от «Вид» и «К результатам». При ошибке можно выйти вверх в шапку Lampa; переход к повтору следует расположению элементов.
- Сообщение ошибки остаётся в области серий без собственного цветного фона, границ и тени. Кнопка повтора сохраняет выделение.
- Прогресс использует общий ключ Lampa.Timeline и привязку к карточке/сезону/эпизоду при наличии Timeline.link. Старый прогресс LamPlay переносится при открытии соответствующих серий, если общий прогресс ещё пуст. Прогресс общий для источников и озвучек.
- Метаданные сезона дополняют список отсутствующими сериями: полупрозрачная миниатюра и номер, название или «Эпизод N», дата и календарный отсчёт. Они доступны для навигации, но не запускаются и не меняют «Продолжить». Неизвестные сведения не выдумываются.
- Filmix: резервный поиск через сайт, сбой профиля не блокирует запрос контента, один повтор при пустом плейлисте/HTTP404/5xx, разбор номеров из видеоссылки. Заголовок User-Agent передаётся только нативному Android-клиенту, как в оригинале. Ограничение качества аккаунта сохраняется при фоновой проверке потоков.

### Границы подтверждения 0.9.0

138 автоматических проверок прошли, включая разрешения 1920×1080, 1280×720, 960×540, 390×844 и 844×390. Это проверка браузерной вёрстки с моделируемыми ответами, а не испытание на реальном LG или Safari iPhone.

Filmix: реальный профиль распознан; для post/176734 с User-Agent приложения получены два сезона, с браузерным User-Agent плейлист пуст даже с тем же аккаунтом. В Chromium с origin http://lampa.mx поиск и token_request читаются (HTTP200). С HTTPS-origin обращения к HTTP API блокируются; рабочий HTTPS API в этой проверке не подтверждён (503/сбой чтения). С учётом сообщения пользователя о работающем оригинале на LG изменён наш путь запросов, но исправление на устройстве пока не подтверждено. Не считать этот пункт полностью закрытым.

HDrezka в браузере телефона остаётся нерешённым: предыдущая проверка выявила ответ без CORS-разрешения; повторные прямые проверки в текущей среде также не дали читаемого ответа. Исправление входа и поиска на iPhone не подтверждено. Прокси не добавлен.

## Изменения 0.8.0

- Виды переименованы: Лента, Список, Витрина. Сохранённые настройки совместимы.
- Правое меню использует системный Lampa.Select: сброс, источник, сезон, перевод.
- Общая геометрия заглавного блока Ленты и Списка, более широкая левая колонка; тайминги удалены из «Продолжить» во всех видах.
- Мягкая виньетка Витрины, отдельный цвет значений фильтров, затухание только переполненного текста.
- Контур и увеличение активной серии: вся строка Списка, только миниатюра Ленты/Витрины. Просмотренные имеют тонкий контур.
- Адаптация к узким и невысоким окнам, прокрутка до элементов, перерасчёт после смены ориентации.
- Ошибка занимает область результатов, заменяя серии/заглушки. Повтор доступен с пульта, «Вид» остаётся доступен.
- Индикатор HDrezka перенесён к «Состояние входа».
- Исправлена регистрация поля токена Filmix для обработчика Params Lampa; статус и привязка устройства сохранены.
- AniLiberty: передаются постер релиза, превью и длительность эпизода из ответа источника; одинаковые источник/озвучка не дублируются.

## Проверка браузерных ограничений 3 ноября 2026

Из браузерного origin http://lampa.mx запрос к https://rezka.fi/ не читается. Сам сайт отвечает HTTP200, но без Access-Control-Allow-Origin. Воспроизведено браузерным fetch с обычной политикой безопасности. Вход также требует разрешённых межсайтовых cookies. Подтверждать исправленный браузерный вход нельзя.

Kodik: публичный скрипт и get-player читаются; get-player вернул HTTP200 и ссылку. Последующий fetch страницы kodikplayer.com блокируется. Доступность сайта или успешный подбор сами по себе не означают доступность разбора плеера из браузера. Прокси не добавлен.

CDNvideohub: пользователь подтвердил работу на телефоне в браузере и в приложении LG. Общие изменения интерфейса проверены отдельно на моделируемых данных.

## Filmix: сведения проверки 0.8.0 (уточнены выше)

Адрес API совпадает с Online Mod: `http://filmixapp.cyou/api/v2/`.
При проверке гостевых запросов с User-Agent приложения получены серии «Братьев», «Гангстерленда» и MP4-потоки. С браузерным User-Agent тот же API возвращает пустой плейлист. Lampa использует нативный HTTP-клиент на Android; на LG/webOS запрос остаётся браузерным, и JavaScript не может выставить нужный User-Agent.

Сценарий привязки реализован, но завершение привязки реального аккаунта, подписка и воспроизведение с его токеном на LG не подтверждены. Успешную авторизацию нельзя считать гарантией устранения ограничения. Прокси не добавлен.

В настройках Filmix нажмите «Добавить устройство на Filmix», войдите в свой аккаунт на https://filmix.gg/consoles и введите код, не закрывая окно в Lampa. После подтверждения токен сохранится автоматически. Для HTTP API сама Lampa также должна быть открыта по HTTP.
